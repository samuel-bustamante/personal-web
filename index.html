Samuel Bustamante-Larriet

PhD student in Computer Science

Oviedo, Asturias, Spain

I am fascinated by knowledge representation, and in particular by knowledge graph technologies and how they hold up when applied to real problems.

I am currently a PhD student in Computer Science at the University of Oviedo, in my first year (since Oct 2026), on a full-time research contract with the WESO (Web Semantics Oviedo) research group, where one of my main responsibilities is the development and maintenance of rudof, an open source library written in Rust that provides tooling for the knowledge graph ecosystem.

Coding

    rudof

    “A semantic-less tool for the Semantic Web”: an open source library written in Rust that provides tooling for the knowledge graph ecosystem. It is published as Rust crates, chief among them rudof_lib; as a command line tool, with binaries for Linux, macOS and Windows; as Python bindings; and as WebAssembly for the browser.
